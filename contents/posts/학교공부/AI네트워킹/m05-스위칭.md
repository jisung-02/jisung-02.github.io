> AI 네트워킹 **중간**범위 — 노션 강의 노트를 옵시디언용으로 정리한 노트.
## 스위치(Switch)란
- 고정 연결을 유지하는 장치가 아니라, **필요할 때만 연결을 만들어주는 장치**.
- 정의 → 스위치에 연결된 둘 이상의 장치 사이에 **임시 연결(temporary connection)**을 생성하는 장치.
- 동작 과정: ① 연결 요청 → ② 경로 생성 → ③ 데이터 전송 → ④ 연결 해제.
- 특징: on-demand 연결 / 자원 공유 가능 / 동적 경로 선택.
- 구성 요소: End system(종단 시스템, A~J) / Switch(중간 장비) / Path(경로).
- 핵심 한 줄 → "Switch는 필요할 때 경로를 만들어주는 시스템".

### 물리적 / 전자적 스위치
- **물리적 스위치**: input → output 직접 연결, 별도 판단(주소 해석) 없음.
- **논리적(전자적) 스위치**: destination(목적지) → next hop(다음 홉)을 결정, 주소를 보고 경로를 판단.

## Switching 분류
```
Switched Networks
├─ Circuit Switching (회선 교환)
├─ Packet Switching (패킷 교환)
│   ├─ Datagram (데이터그램)
│   └─ Virtual Circuit (가상 회선)
└─ Message Switching (메시지 교환, 현재는 사용 X)
```

| 구분 | Circuit Switching | Datagram | Virtual Circuit |
| --- | --- | --- | --- |
| 방식 | 연결 먼저(setup), 경로 고정 | 패킷 단위, 경로 매번 결정 | 초기 경로 설정 후 같은 경로 사용 |
| 경로 | 고정 | 매번 변경 | 초기 설정 후 고정 |
| 자원 | 미리 할당(독점) | on-demand(필요할 때) | 혼합(setup 또는 on-demand) |
| 순서 | 보장 | 보장 X (재조립 필요) | 같은 경로라 순서 유지 |
| 효율 | 낮음 | 높음 | 중간 |
| 지연 | 거의 없음 | 큼(공유+라우팅 결정) | 중간 |
| 구현 계층 | 물리 계층(L1) | 네트워크 계층(L3) | 데이터 링크 계층(L2) |

## Circuit Switching (회선 교환)
- 회선 교환 네트워크 = 물리적 링크로 연결된 스위치들의 집합.
- 두 스테이션 간 연결 = 하나 이상의 링크로 이루어진 **전용 경로(dedicated path)**.
- 각 링크는 보통 **FDM 또는 TDM**으로 n개의 채널로 분할되며, 하나의 연결은 각 링크에서 **채널 1개씩만**사용.

### 3단계 동작 (예: A → M)
1. **Setup(설정)**: A가 M으로 연결 요청 → 모든 스위치와 M이 승인 → 각 링크에 채널 1개씩 예약하여 전용 경로 수립.
2. **Data transfer(데이터 전송)**: 채널 확보 완료 상태이므로 데이터가 곧장 전송.
3. **Teardown(해제)**: 모든 데이터 전송 후 회선 해제.

### 효율성과 지연
- **효율 ↓**: 자원이 연결 전체 기간 동안 할당되어, 다른 연결이 그 자원을 못 씀.
- **지연 ↓**: 데이터 전송 중 각 스위치에서 지연되지 않음(자원이 이미 점유됨). 채널을 공유하지 않아 지연이 낮음.

### 구조적 한계
- 경로를 미리 만들고 끝까지 독점 → 다른 사람 못 씀, 자원 낭비, 양방향 충돌 가능.
- **확장성 문제**: N개 장치 → 필요한 연결 수 = N × (N − 1) / 2. 장치가 늘면 연결 수가 급증.
- **Crossbar Switch 문제**: 입력↔출력 직접 연결 시 N input × N output → **N² 개 스위치**필요 → 하드웨어 복잡도·비용 증가.
- **유연성 없음**: 한번 회선을 잡으면 다른 경로가 여유 있어도 전환 불가.

## Datagram (데이터그램 네트워크)
- "메시지를 쪼개서 각각 따로 보내는 방식". 패킷 교환 네트워크의 한 종류(패킷 교환 ⊃ 데이터그램).
- 메시지는 고정/가변 크기 패킷으로 나뉨 (크기는 네트워크·프로토콜이 결정).
- **자원 예약 없음**→ 전송할 패킷이 있을 때만 자원 할당.
- 각 패킷은 **다른 패킷과 독립적으로**처리됨.

### 독립 처리로 인한 특징
1. 같은 데이터를 나눈 패킷이라도 매번 다른 경로로 갈 수 있음.
2. 수신 단 도착 순서가 바뀔 수 있음.
3. 회선을 점유하지 않고 공유 → 효율적.
4. 그러나 공유 때문에 전송 지연시간이 커짐.
5. 라우터가 매번 어디로 보낼지 결정 → 결정 지연시간 추가.

### 라우팅 테이블
- 데이터그램 스위치는 **목적지 주소 → Output Port**를 대응하는 라우팅 테이블 사용.
- 패킷 헤더의 **목적지 주소는 전체 이동 동안 동일하게 유지**.

### 효율성 & 인터넷
- 자원을 패킷이 있을 때만 할당하고 채널을 공유 → 회선 교환보다 효율 높음.
- **인터넷(IP)**은 네트워크 계층에서 **데이터그램 방식**으로 패킷 교환.

### 데이터그램 방식과 AI
- 라우터가 패킷 경로를 매번 결정하되 **현재 상황만**파악 가능 → 이 지점에 AI 개입 여지.
- 라우터에 AI 에이전트를 접목하면 **트래픽 예측 / 혼잡 예측 / 최적 경로 선택**으로 미래 상황까지 고려한 경로 결정 가능.

## Virtual Circuit (가상 회선 네트워크)
- 회선 교환과 데이터그램의 **교차(혼합)**형태 — 양쪽 장점을 가짐.
- 논리적으로 가상의 회선을 만들어 동작하는 네트워크.

### 회선 교환과의 공통점
- **Setup / Data / Teardown**3단계 존재(연결 개념 있음).
- 모든 패킷이 연결 동안 **동일한 경로**를 따름.

### 데이터그램과의 공통점
- 데이터가 패킷화되고 각 패킷이 헤더에 주소를 가짐 (단, 전역 주소가 아닌 **로컬 범위 주소 VCI**).
- 각 패킷이 경로를 공유할 수 있음.

### 자원 할당 & 구현 계층
- 자원 할당 두 방식: ① Setup 때 할당(Circuit 방식) ② 필요할 때 할당(Datagram 방식).
- 구현 계층: 가상 회선 = **데이터 링크 계층(L2)**/ 회선 교환 = 물리 계층 / 데이터그램 = 네트워크 계층.

### 주소 체계: Global Address vs VCI
- **Global Address(전역 주소)**: WAN/국제 범위에서 유일. 초기 회선 **설정 단계에서만**사용, 실제 전송엔 안 씀. 셋업 때 전역 주소를 VCI로 전환.
- **VCI (Virtual Circuit Identifier, 가상 회선 식별자)**: 실제 데이터 전송에 사용되는 작은 로컬 번호. 두 스위치 사이 프레임에서 사용. 스위치 범위에서만 의미.
 - 매 홉마다 바뀜 (예: 스위치 통과 시 14 → 77).
 - 스위치 내부 매핑: (port 1, VCI 14) → (port 3, VCI 77).
 - 링크마다 독립 관리 → 번호 재사용 가능 / 충돌 없음 / 테이블 작아짐.
- **전역 주소가 느린 이유**: 전역 주소를 모두 관리하면 라우팅 테이블이 커져 lookup 시간 증가, 패킷마다 경로 계산 필요, VCI보다 길고 계산이 오래 걸림.

### 3단계(Three Phase)
1. **Setup Phase**: Global Address 사용 → 경로 생성 → VCI 생성 → 스위치 테이블 생성. (설정 요청 + 승인 두 단계)
2. **Data Transfer Phase**: VCI 기반 forwarding, 동일 경로 사용, 빠른 전송. 모든 스위치에 해당 VC의 테이블 entry가 있어야 전달 가능.
3. **Teardown Phase**: 출발지 A가 Teardown Request(제어 프레임) 전송 → 목적지 B가 Teardown Confirmation 응답 → 그 프레임이 지나갈 때 각 스위치가 테이블 항목 삭제.

### SVC vs PVC
- **SVC (Switched Virtual Circuit)**: 데이터 전송 중에만 존재하는 임시·짧은 연결. setup → data transfer → teardown 단계 존재.
 - 설정 요청 시: 각 스위치 VC Table의 **Incoming Port·VCI**매핑.
 - 설정 acknowledgement 시: 되돌아오며 각 스위치 VC Table의 **Outgoing Port·VCI**매핑.
- **PVC (Permanent Virtual Circuit)**: 미리 설정한 영구적 고정 경로.

### 지연 특성
- on-demand 할당이면 같은 경로라도 도착 시간이 다를 수 있음(스위치에서 다른 패킷을 기다릴 수 있음).
- 회선 교환은 setup 때 점유하므로 이런 대기 문제 없음.
- Switched WAN의 데이터 링크 계층 스위칭은 보통 가상 회선 기술로 구현 (빠른 forwarding + 라우팅 부담 감소).
