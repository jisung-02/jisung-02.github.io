에이전트를 단순 stateless 도구가 아니라 **자율적으로 소통·협업하는 피어(peer)**로 다루는 오픈 프로토콜(출시 1년 경과). 에이전트끼리 작업을 위임·협상.

## 푸는 문제
- **컨텍스트 폭주**: 복잡한 다단계 의존성을 메인 에이전트가 다 떠안지 않음.
- **데이터 보안**: 내부 데이터·프로세스를 캡슐화한 "블랙박스" 핸드오프.
- **API 한계**: 고정·결정적 API를 넘어 동적 자율 협업.
- **분업**: 모놀리식 대신 도메인 전문가가 모듈 단위로 구축.

## 동작 핵심
- **보안 경계**: 작업을 전문 에이전트에 위임, 각자 자기 환경 유지.
- **동적 자율성**: 받는 쪽이 계획을 다듬고, 거절하고, 되묻기 가능 (API는 데이터 반환 or 실패뿐).
- **컨텍스트 보존**: 각 에이전트가 자기 상태만 관리 → 남의 메모리 오염 X.
- (Agent Card: 에이전트가 자기 능력·엔드포인트를 광고하는 메타데이터 — 발견·연결의 단위)

## 채택 현황 (SDK)
- Python·Go: **1.0 GA**
- Java(Beta)·.NET(Preview): GA 진행 중
- JS/TS: v0.3, 1.0 작업 중
- 활용: 커머스, 엔터프라이즈 데이터 스트리밍, IT/DevOps 오케스트레이션, 규제 통신망.

## 메모
- 예시 FoldRun: 페타바이트급 단백질 구조 예측을 전문 에이전트 인터페이스에 위임 → 인프라 부담 제거.
- [[agentic-resource-discovery]]가 "찾기" 계층이면, A2A는 찾은 에이전트끼리 "협업하는" 계층.
