## 핵심 개념 (Lec 02 상세)

### ML 3대 카테고리
| 종류 | 데이터 | 목표 | 대표 작업 |
|---|---|---|---|
| 지도 학습 Supervised | Label 있음 | Feature→Target 관계 학습 | 분류(Classification), 회귀(Regression) |
| 비지도 학습 Unsupervised | Label 없음 | 숨은 구조/패턴 | 군집화(Clustering), 차원축소 |
| 강화 학습 Reinforcement | 보상 신호 | Reward 최대화 Policy | 게임·로봇·자율주행 |

### 지도 학습 7단계
1. 데이터 수집 → 2. 전처리(표준화·crop·레이블) → 3. 특성 추출(딥러닝은 생략 가능) → 4. 학습 샘플 $(x_i,y_i)$ 생성 → 5. 손실 함수 선택 → 6. 모델 학습(손실 최소화) → 7. 일반화 오류 평가(Test Data)

### ML의 과제
- 견고성 부족: 적대적 예제(Adversarial Example, 팬더+노이즈→긴팔원숭이)
- 데이터 편향: 다양성 부족 시 불공정 결과
- 윤리: 범죄예측 편향 등. "magic black box"로 취급하지 말 것

## 핵심 수식 / 예시

손실 함수 예 (제곱 오차 합):
$$\sum_i (y_i - \hat y_i)^2$$

최소제곱 해의 두 형태 (Lec 04-09 관통):
$$\hat w = (X^TX)^{-1}X^Ty \quad\xrightarrow{\text{SVD}}\quad \hat w = V\Sigma^+U^Ty$$
