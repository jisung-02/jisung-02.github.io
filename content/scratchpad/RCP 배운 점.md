## os.Exit()
- 현재 프로그램을 해당 상태 코드로 즉시 종료
- 관계적으로 0은 성공(정상 종료), 0이 아닌 값은 오류를 의미
- `os.Exit()`은 프로그램을 즉시 종료하므로 `defer`는 실행되지 않음
- 종료 상태 코드는 0부터 125 사이**만 쓰는 게 안전
	- 여러 OS, 쉘, 실행 환경에서 의미가 꼬이지 않게 하기 위함

| **코드**          | **의미**                                    |
| --------------- | ----------------------------------------- |
| 0               | 정상 종료, 성공                                 |
| 1               | 일반적인 실패                                   |
| 2               | 잘못된 사용법, 인자 오류 등에 자주 사용                   |
| 0보다 큰 값         | 실패 또는 특수 상태                               |
| 126, 127, 128+N | 쉘에서 특별한 의미로 쓰이는 경우가 많아 직접 쓰는 것을 피하는 편이 안전 |
