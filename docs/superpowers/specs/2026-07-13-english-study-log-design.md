# 영어 공부 일지 설계

## 목표

영어 공부 내용을 날짜별로 채워 넣을 수 있는 비공개 일지 템플릿을 추가한다.

## 콘텐츠 구조

- 새 카테고리 디렉터리: `contents/posts/영어 공부/`
- 오늘의 일지: `contents/posts/영어 공부/2026-07-13.md`
- 생성 URL: `/posts/영어-공부/2026-07-13/`
- 이후에는 일지 파일을 복사하고 날짜만 바꿔 같은 형식을 재사용한다.

## 프런트매터

- `title`: `2026-07-13 영어 공부`
- `date`: `2026-07-13`
- `publish`: `false`
- `tags`: `영어`, `학습일지`
- `description`: `2026년 7월 13일 영어 학습 기록`

카테고리는 디렉터리 경로에서 생성되므로 프런트매터에 `category`를 추가하지 않는다.

## 본문 템플릿

내용을 자유롭게 채울 수 있도록 다음 빈 섹션만 제공한다.

1. 오늘의 목표
2. 단어·표현
3. 예문
4. 듣기·말하기
5. 복습·회고

## 검증

`npm run build`를 실행해 콘텐츠 스키마, 새 경로, 내부 링크 검증이 모두 통과하는지 확인한다. 글은 `publish: false`이므로 프로덕션 목록에는 노출되지 않아야 한다.
