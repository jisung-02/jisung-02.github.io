# portfolio-blog

Markdown 기반 콘텐츠를 Hugo로 렌더링하고, React 위젯으로 빠른 탐색 기능을 추가한 개인 포트폴리오/블로그입니다.

## 요구 도구

- Node.js 22+
- npm 10+
- Hugo extended (https://gohugo.io/)

## 개발/검증 명령

```bash
npm install
npm run lint
npm run typecheck
npm run test
npm run check-content
npm run build
npm run audit
```

빌드 결과물은 `dist/`에 생성됩니다.
