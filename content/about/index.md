이 공간은 포트폴리오 쇼케이스보다 **재사용 가능한 실행 기록**을 남기기 위해 운영합니다.
핵심은 "나중에도 다시 꺼내 쓸 수 있는 문서"입니다.

## 운영 프레임워크

- **PARA**: Projects / Areas / Resources / Archives로 메모를 분류합니다.
- **CODE 루프**: Capture → Organize → Distill → Express를 주간 단위로 반복합니다.
- **DoD 중심 관리**: Outcome(완료 기준), Deadline, Next Actions를 함께 고정합니다.

## 운영 규칙

1. 하루에 `NEXT` 작업 3개만 실행합니다.
2. `NEXT` WIP는 최대 7개로 제한합니다.
3. 주 1회(30~45분) 주간 리뷰를 실행합니다.
4. 완료 항목은 Archive Queue로 이동해 기록을 닫습니다.

## 문서 공개 기준

- 개인/팀 민감 정보(IP, 계정, 비밀번호)는 제거한 뒤 공개합니다.
- 문제, 명령, 검증 결과를 재사용 가능한 형태로 남깁니다.
- 링크와 구조는 주기적으로 점검해 깨진 경로를 줄입니다.

## 기술 구성

- Hugo + Markdown: 정적 문서 작성/배포
- TypeScript scripts: 콘텐츠/빌드 검증 자동화
- GitHub Pages: 운영 단순화
